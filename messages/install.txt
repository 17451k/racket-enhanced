Racket
======

Thanks for installing. Racket syntax highlighting is now active for .rkt,
.rktl and .rktd files, and Scribble highlighting for .scrbl files.

What you get now:
  - Goto Symbol (Ctrl/Cmd+R) lists every defined function and struct.
  - Toggle Comment (Ctrl/Cmd+/) inserts "; "; block comment inserts #| |#.
  - Enter after an open bracket indents; a close bracket outdents.
  - Double-click selects whole identifiers such as string->list or null?.
  - Build system (Tools > Build With...): Run, Test, Test Directory, Compile,
    Format (needs `raco pkg install fmt`), Expand, Check Requires. Error
    locations in the output are clickable. racket and raco must be on the
    PATH Sublime sees.

Please report highlighting problems if you encounter one, preferably with a minimal snippet.
