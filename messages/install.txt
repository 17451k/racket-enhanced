Racket Enhanced
===============

Thanks for installing.

If you also have the "Racket" package installed, both packages claim the
`source.racket` scope and the .rkt extension, and Sublime may pick either one.
Disable the old package:

  Preferences > Settings, then add "Racket" to "ignored_packages":

    "ignored_packages": ["Racket", "Vintage"],

or uninstall it via Package Control: Remove Package > Racket.

Already-open .rkt tabs keep their previous syntax; reopen them, or use
View > Syntax > Open all with current extension as... > Racket.
